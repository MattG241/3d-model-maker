How to import into Roblox
  1. Download the .obj (offline) or .fbx/.obj (AI).
  2. Studio → Asset Manager → Bulk Import → pick the file.
  3. Drag the imported MeshPart into your place.
  4. AI meshes can be high-poly — see AI_MODELS.md for optimizing.
Where do I get a free API key?

Meshy: meshy.ai → Settings → API. Tripo: platform.tripo3d.ai → API keys. Your key is stored only in this browser and sent only to your local app.
